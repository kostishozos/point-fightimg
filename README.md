# Point Fighter

Arcade 2D point-fighting game. Play in the browser, or install it:

- **Phone:** open the game's website, then Share → Add to Home Screen (iPhone) or menu → Install app (Android).
- **Laptop:** open it in Chrome or Edge and click the install icon in the address bar.

Controls: ← → move · W reverse punch · E blitz · D side kick · F head kick · A defensive kick · 1 + W/D fake.
Game controllers and touch controls are supported.
